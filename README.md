# The Vacuum's Alibi

One line, 98 characters: the excuse a robot vacuum gives for missing a spot. Entry for the make.fun bounty "The Vacuum's Alibi" ($5).

`main.py` writes the line to `/output/entry.txt` and validates it is 1 to 200 characters on a single line.
